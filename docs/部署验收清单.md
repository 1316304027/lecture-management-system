# 部署验收清单 — 每版 push 后执行

## 本地确认（push 前）

```bash
cd /mnt/c/Users/yuzhe/lecture-management-system/demo
git status
git add .
git commit -m "描述你改了什么"
git push
```

---

## EC2 部署（必做 4 步）

```bash
ssh -i ~/.ssh/lecture-key.pem ec2-user@你的EC2IP

cd ~/lecture-management-system
git pull
./mvnw clean package -DskipTests
sudo docker restart app-app-1
```

浏览器打开 `http://EC2_IP/login`，按 **Ctrl+Shift+R** 强制刷新。

## 常见问题

| 现象 | 解决 |
|------|------|
| git pull 没变化 | 本地先 git push |
| 页面没变化 | Ctrl+Shift+R |
| SSH 连不上 | 安全组加 マイ IP |
| 500 错误 | `sudo docker logs app-app-1` 看日志 |
