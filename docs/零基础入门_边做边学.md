## 二、你现在是怎么用 Cursor 改代码的？

可以把它想成：**你说话，AI 动手改文件。**

### 你已经在做的事

1. 用 **Cursor** 打开文件夹 `lecture-management-system\demo`
2. 在 **Chat（对话）** 里用中文告诉我：要改什么、发表要什么效果
3. **我（Agent）** 直接修改项目里的文件
4. 你在左侧 **文件树** 里能看到文件被改了
5. 你按 **AWS部署步骤指南** push 到 EC2 看效果

**这就是「用 Cursor 改代码」。** 不是你手写每一行，而是你 **提需求 + 验收 + 学原理**。

### 你怎么配合 AI 最高效？

| 你说什么 | AI 能做什么 |
|----------|-------------|
| 「学生主页太丑，改成 Dashboard」 | 改 `student-home.html` + CSS |
| 「还原上一版」 | git 或改回文件 |
| 「教我 login 怎么连数据库」 | 写进学习笔记，用大白话讲 |
| 「做第二版：出席页也统一风格」 | 改 `student-attendance.html` 等 |

**小技巧：**

- 在对话里 **@ 文件名**（如 `@login.html`）让我对准那个文件改  
- 改完你自己打开文件 **扫一眼**，不用全懂  
- 不懂就问：「这 3 行是干啥的？」我会写进 `PRESENTATION_LEARN.md`

### 你要会的一点点 Git（4 条命令够用）

```bash
git status          # 看改了哪些文件
git add .           # 准备提交
git commit -m "说明"  # 保存一个版本（方便还原）
git push            # 上传到 GitHub，EC2 才能 pull
```

## 三、这个系统是咋回事？（没基础版）

### 用饭店比喻

| 词 | 比喻 | 你项目里 |
|----|------|----------|
| **浏览器** | 顾客 | Chrome 打开网页 |
| **Controller** | 服务员接单 | 收到「我要学生主页」 |
| **Service** | 厨师做菜 | 查数据库、算出席率 |
| **Repository** | 仓库管理员 | 从 PostgreSQL 取数据 |
| **Entity** | 菜谱上的菜名 | `Course.java` = courses 表 |
| **templates/*.html** | 盘子摆盘（长什么样） | Thymeleaf 网页 |
| **RDS** | 仓库建在云上 | AWS 数据库 |
| **EC2** | 厨房建在云上 | 跑 Spring Boot 的机器 |
| **S3** | 文件柜 | 存 PDF |

### 学生打开主页时发生了什么？

```
1. 你点登录 → 浏览器访问 /student/home
2. StudentController 接到请求
3. 问 CourseService：这个学生有哪些课？
4. Service 让 Repository 去 RDS 查表
5. 查到的课程列表塞进 student-home.html
6. 浏览器显示你看到的 Dashboard
```

**第一版 UI 只改了第 6 步「长什么样」，1～5 步完全没动。**

## 四、为什么你家电脑直接跑会失败？

`application.yaml` 里写的是 **AWS RDS 的地址**。

- **EC2 上跑** → 在 AWS 内部，能连 RDS ✅  
- **你家电脑跑（默认配置）** → 互联网连 RDS，常被防火墙挡住 ❌ timeout  

所以你的策略 **「改代码 + 直接在 AWS 上看」是对的。**

## 五、边做边学 — 每版你要会什么？

不用一次学完 Java。每改一版，只多会 **3 句话**：

### 第一版（已完成）

1. **login.html** = 登录页长什么样  
2. **student-home.html** = 学生登录后看到的页  
3. **pcfa-theme.css** = 全站颜色、卡片样式  

发表台词和 Q&A → 看 **`PRESENTATION_LEARN.md`**

### 第二版（计划）

- 出席 / 课题 / 聊天 套同一主题  
- 笔记会 **追加** 到 `PRESENTATION_LEARN.md` 新章节  

### 你每天的 15 分钟学习（发表前）

1. 打开 `PRESENTATION_LEARN.md` 读一节（5 分钟）  
2. 用自己的话说一遍「这个页面干什么」（5 分钟）  
3. 念一遍日语发表句（5 分钟）
