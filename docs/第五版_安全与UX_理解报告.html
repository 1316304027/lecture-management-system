二、密码安全（领导指摘 — 最重要）

以前的问题

管理员创建用户时直接输入密码 → 领导认为违反信息安全（管理员知道用户密码）。

现在的流程

【创建用户】
管理员只填：氏名 + メール + ロール
  → UserService.createUser() 自动生成12位随机密码
  → BCrypt 哈希存入 DB
  → password_reset_required = true
  → 画面仅一次显示初期パスワード（黄色警告框）

【用户首次登录】
POST /login 成功
  → 若 password_reset_required=true
  → redirect /change-password
  → 用户自己设新密码（8字以上）
  → password_reset_required=false → 进入主页

【管理员重置】
操作列「PWリセット」按钮
  → POST /admin/accounts/{id}/reset-password
  → 同样发新随机密码，仅显示一次
你必须能说：管理员看不到、不能改用户日常密码；只能触发系统重新发临时密码，用户下次登录必须自己改。
日语 · 领导问安全
管理者はユーザーのパスワードを直接設定・変更できません。システムが初期パスワードを自動発行し、受講者は初回ログイン時に本人が新しいパスワードへ変更します。これは情報セキュリティのベストプラクティスです。

七、Q&A（社长 + 领导）

密码为什么不能让管理员设？

管理者がユーザーのパスワードを知ると情報漏洩リスクがあります。自動発行と本人変更により、パスワードは本人のみが管理します。

是不是大改动？

不大。加了 password_reset_required 字段、/change-password 页面、改了几个 Controller 方法。核心仍是 Session + BCrypt。

お知らせ和教材有什么区别？

教材はPDFファイル、お知らせはテキスト連絡です。用途が違うため画面とDBを分けています。
