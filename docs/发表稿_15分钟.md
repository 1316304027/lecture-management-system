## 4. 技术架构（3 分钟）

> バックエンドは Spring Boot、画面は Thymeleaf の SSR 構成です。  
> データは RDS PostgreSQL、ファイルは S3 に保存しています。  
> EC2 上で Docker + Nginx により本番稼働しています。

**画架构图（或指幻灯片）：**
```
Browser → EC2(Nginx) → Spring Boot → RDS
                              ↘ S3 (Presigned URL)
```

**Presigned URL 一句话：**
> ブラウザが S3 に直接アップロードするため、サーバー負荷を軽減できます。

## 社长可能问的 10 个 Q&A

**Q1. なぜ Spring Boot？**  
> Java の標準的フレームワークで、JPA・Security・Thymeleaf を統合しやすいためです。

**Q2. セキュリティは？**  
> BCrypt パスワード、Session 認証、ロール別画面分岐、5回失敗でロックです。

**Q3. S3 を使う理由は？**  
> 教材・課題・顔写真などファイルをスケーラブルに保存するためです。

**Q4. Presigned URL とは？**  
> 一時的な署名付き URL で、ブラウザが S3 に直接アクセスします。

**Q5. なぜ Lambda ではなく DB でチャット既読？**  
> 研修期間内はシンプルな DB 管理で十分。Lambda は将来の拡張です。

**Q6. 未採点の課題はどう表示？**  
> 0点扱いせず「採点待ち」と表示するよう改善しました。

**Q7. デプロイ方法は？**  
> GitHub → EC2 git pull → Maven build → Docker restart です。

**Q8. ローカル開発は？**  
> docker-compose.local + profile=local で PostgreSQL を使います。

**Q9. AI に頼りすぎでは？**  
> 補助ツールとして使用。設計意図とデプロイは自分で実施しています。

**Q10. 今後の課題は？**  
> 認証統合、UI 改善、テスト、チャットのリアルタイム化です。
