## 二、CSS 是什么？（5 分钟入门）

把网页想成 **房子**：

| 部分 | 文件 | 作用 |
|------|------|------|
| 结构 | `.html` | 门在哪、按钮有几個 |
| 装修 | `.css` | 颜色、大小、对齐、阴影 |

你项目里统一主题在这：

```
src/main/resources/static/pcfa-theme.css
```

每个页面头部加一行就会用这套样式：

```html
<link rel="stylesheet" th:href="@{/pcfa-theme.css}">
```

```html
<body class="pcfa-body">
```

**你要学的不是背 CSS**，只要会：

1. 打开 `pcfa-theme.css` 看 `--pcfa-primary` 是主题绿色  
2. 知道改 `.pcfa-course-action` 会影响课程卡片里按钮高度  
3. 发表时说：「共通 CSS で画面を統一しました」
