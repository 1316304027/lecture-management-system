# 受講者 93 名 — 1回だけ投入する手順

## やることは1回だけ

1. 管理者でログイン
2. ブラウザで開く：**http://35.77.43.229/admin/setup/seed-students**
3. 「今回だけ XX 名を追加する」を **1回** 押す
4. ユーザー管理で **93 名** になったか確認

**再起動しても自動では増えません。** 上の画面で押したときだけ実行されます。

## データはどこに入る？

| 項目 | 内容 |
|------|------|
| 保存先 | AWS RDS → データベース `lecturedb` → 表 `users` |
| コード | `UserService.seedAdditionalDemoStudents()` |
| 操作 | `userRepository.save(user)` → SQL の INSERT |
| 氏名 | 姓20種＋名20種を Java の `Random` で組み合わせ |
| メール | student001@demo.pcfa.jp 〜（空き番号） |
| パスワード | Admin1234（BCrypt 暗号化して users に保存） |
| コース割当 | あれば `course_users` 表にも INSERT |

## ログイン（追加した人）

- メール：student001@demo.pcfa.jp など
- パスワード：Admin1234
